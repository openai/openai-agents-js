## 개요

[TypeScript용 OpenAI Agents SDK](https://github.com/openai/openai-agents-js)는 애플리케이션 코드에서 에이전트 워크플로를 구축하기 위한 오픈 소스 프레임워크입니다. [Swarm](https://github.com/openai/swarm/tree/main)을 기반으로 가드레일과 내장 트레이싱을 갖춘 경량 멀티 에이전트 오케스트레이션을 프로덕션 애플리케이션에 제공합니다. SDK는 [Python으로도 제공됩니다](https://github.com/openai/openai-agents-python).

SDK는 애플리케이션에서 에이전트 루프를 실행하며 MCP 서버 도구를 포함한 모델 호출과 도구 실행을 조정합니다. 세션은 여러 실행에 걸쳐 대화 컨텍스트를 유지하며, 사람의 승인을 통해 애플리케이션이 검토를 위해 도구 실행을 일시 중지할 수 있습니다. SDK는 다음과 같은 소수의 기본 구성 요소를 제공합니다.

- **에이전트**: instructions와 tools를 갖춘 LLM
- **샌드박스 에이전트**: 에이전트에 격리된 파일 시스템 작업 공간, 셸 명령, 파일 편집, 스냅샷 및 샌드박스 세션 상태를 결합
- **음성 에이전트**: 도구, 가드레일, 핸드오프 및 대화 기록을 활용하는 저지연 음성 상호작용 지원
- **Agents as tools 및 핸드오프**: 에이전트가 특정 작업을 다른 에이전트에 위임할 수 있도록 지원
- **가드레일**: 에이전트 입력 검증 지원

이러한 기본 구성 요소를 TypeScript와 함께 사용하면 도구와 에이전트 간의 복잡한 관계를 표현하고, 필요할 때 에이전트에 실제 작업 공간을 제공하며, 가파른 학습 곡선 없이 실제 애플리케이션을 구축할 수 있습니다. 또한 SDK에는 에이전트 흐름을 시각화하고 디버깅할 수 있는 내장 **트레이싱**이 포함되어 있으며, 이를 평가하고 애플리케이션에 맞게 모델을 미세 조정할 수도 있습니다.

## Agents SDK 사용 이유

SDK는 다음 두 가지 설계 원칙을 따릅니다.

1. 사용할 가치가 있을 만큼 충분한 기능을 제공하면서도, 빠르게 배울 수 있도록 기본 구성 요소의 수를 최소화합니다.
2. 별도 설정 없이도 원활하게 작동하면서, 동작을 정확히 원하는 대로 사용자 지정할 수 있습니다.

SDK의 주요 기능은 다음과 같습니다.

- **에이전트 루프**: 도구 호출을 처리하고 결과를 LLM에 다시 전송하며 작업이 완료될 때까지 계속 실행하는 내장 에이전트 루프
- **샌드박스 실행**: 작업 공간이 필요한 경우 격리된 파일 시스템 작업 공간, 셸 명령, 파일 편집, 스냅샷 및 샌드박스 세션 상태를 사용하여 에이전트 실행
- **음성 에이전트**: 자동 인터럽션(중단 처리) 감지, 컨텍스트 관리, 가드레일 등의 기능을 사용한 저지연 음성 상호작용 구축
- **TypeScript 우선**: 새로운 추상화를 배울 필요 없이 네이티브 TypeScript 언어 기능을 사용하여 에이전트를 오케스트레이션하고 연결
- **Agents as tools 및 핸드오프**: 여러 에이전트 간의 작업을 조정하고 위임하는 강력한 메커니즘
- **가드레일**: 입력 검증과 안전성 검사를 에이전트 실행과 병렬로 수행하고, 검사를 통과하지 못하면 즉시 실패 처리
- **함수 도구**: 자동 스키마 생성과 스키마 기반 검증을 통해 모든 TypeScript 함수를 도구로 변환
- **MCP 서버 도구 호출**: MCP 서버의 도구를 함수 도구와 함께 에이전트에 제공하는 내장 연동
- **세션**: 에이전트 루프 내에서 작업 컨텍스트를 유지하기 위한 영구 메모리 계층
- **휴먼인더루프 (HITL)**: 여러 에이전트 실행에 걸쳐 사람을 참여시키기 위한 내장 메커니즘
- **트레이싱**: 워크플로를 시각화, 디버깅 및 모니터링하기 위한 내장 트레이싱으로, OpenAI의 평가, 미세 조정 및 증류 도구 모음 지원

## 설치

```bash
npm install @openai/agents zod
```

SDK에는 Zod v4가 필요합니다. npm을 통해 `zod`를 설치하면 최신 v4 릴리스를 가져옵니다.

## 시작 지점 선택

처음 사용하는 대부분의 사용자는 다음 진입점 중 하나만 필요합니다.

| 시작 항목 | 사용 시점 | 참고 |
| --- | --- | --- |
| `@openai/agents` | 대부분의 텍스트, 샌드박스 또는 실시간 애플리케이션을 구축할 때 | 권장 기본값입니다. OpenAI 제공자 설정, `@openai/agents/sandbox`의 샌드박스 에이전트 API 및 `@openai/agents/realtime`의 실시간 API가 포함됩니다. |
| `@openai/agents-realtime` | 독립형 Realtime 패키지만 필요할 때 | 브라우저 전용 실시간 앱이나 더 좁은 패키지 경계를 원하는 경우 유용합니다. |
| 하위 수준 패키지 (`@openai/agents-core`, `@openai/agents-openai`, `@openai/agents-extensions`) | 하위 수준 구성, 사용자 지정 제공자 연결 또는 특정 연동이 필요할 때 | 구체적인 필요가 생길 때까지 대부분의 신규 사용자는 이러한 패키지를 무시해도 됩니다. |
