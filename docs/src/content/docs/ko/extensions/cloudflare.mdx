Cloudflare Workers 및 기타 workerd 런타임에서는 전역 `WebSocket` 생성자로 아웃바운드 WebSocket 연결을 열 수 없습니다. 이러한 환경에서 음성 에이전트를 더 쉽게 연결할 수 있도록, 확장 패키지는 내부적으로 `fetch()` 기반 업그레이드를 수행하는 전용 전송 계층을 제공합니다.

<Aside type="caution">
  이 어댑터는 아직 베타 버전입니다. 특수한 상황에서 문제가 발생하거나 버그가
  있을 수 있습니다. 문제가 발생하면 [GitHub
  이슈](https://github.com/openai/openai-agents-js/issues)를 통해 알려 주시기
  바랍니다. 신속하게 수정하겠습니다. Workers에서 Node.js 스타일 API를 사용하려면
  `nodejs_compat` 활성화를 고려하시기 바랍니다.
</Aside>

## 설정

<Steps>

1. **확장 패키지를 설치합니다.**

   ```bash
   npm install @openai/agents-extensions
   ```

2. **전송 계층을 생성하고 세션에 연결합니다.**

   <Code lang="typescript" code={cloudflareBasicExample} />

3. **`RealtimeSession`을 연결합니다.**

   ```typescript
   await session.connect({ apiKey: 'your-openai-ephemeral-or-server-key' });
   ```

</Steps>

## 참고 사항

- Cloudflare 전송 계층은 내부적으로 `Upgrade: websocket`을 지정한 `fetch()`를 사용하며, workerd API에 맞춰 소켓의 `open` 이벤트를 기다리지 않습니다.
- 이 전송 계층을 사용할 때도 모든 `RealtimeSession` 기능(도구, 가드레일 등)은 평소처럼 작동합니다.
- 개발 중 상세 로그를 확인하려면 `DEBUG=openai-agents*`를 사용합니다.
