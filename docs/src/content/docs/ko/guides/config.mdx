### 디버그 로깅

SDK는 디버그 로깅에 [`debug`](https://www.npmjs.com/package/debug) 패키지를 사용합니다. 상세 로그를 보려면 `DEBUG` 환경 변수를 `openai-agents*` 값으로 설정하세요.

```bash
export DEBUG=openai-agents*
```

세션 영속화 작업을 기록하려면 `OPENAI_AGENTS__DEBUG_SAVE_SESSION=1` 환경 변수를 설정하세요.

`@openai/agents` 패키지의 `getLogger(namespace)` 함수를 사용하면 자체 모듈용으로 네임스페이스가 지정된 로거를 얻을 수 있습니다.

#### 로그의 민감한 데이터

관련 오류 객체와 세부 정보를 포함한 모델 및 도구 데이터는 기본적으로 로그에 포함되지 않습니다. 디버깅 중에 이러한 세부 정보가 필요하다면 프로세스의 민감한 데이터 로깅을 명시적으로 활성화할 수 있습니다.

<Code
  lang="typescript"
  code={setSensitiveDataLoggingEnabledExample}
  title="민감한 데이터 로깅 활성화"
/>

로그를 안전하게 처리하는 환경에서만 이 기능을 활성화하세요. 프로그래밍 방식의 설정은 모델 및 도구 데이터를 모두 제어하며, 아래 환경 변수보다 우선합니다. 민감한 데이터 로깅을 다시 비활성화하려면 `setSensitiveDataLoggingEnabled(false)` 함수를 호출하세요.

환경 변수를 사용해 모델 및 도구 데이터 로깅을 각각 활성화할 수도 있습니다. 해당하는 `OPENAI_AGENTS_DONT_LOG_*` 변수를 `0` 또는 `false` 값으로 설정하세요.

```bash
export OPENAI_AGENTS_DONT_LOG_MODEL_DATA=0
export OPENAI_AGENTS_DONT_LOG_TOOL_DATA=0
```

어느 변수든 `1` 또는 `true` 값으로 설정하면 해당 데이터와 관련 오류 세부 정보가 계속 가려집니다. 값이 설정되지 않았거나 인식할 수 없는 값인 경우에도 안전한 기본값이 사용되어 민감한 데이터가 로그에 포함되지 않습니다.
