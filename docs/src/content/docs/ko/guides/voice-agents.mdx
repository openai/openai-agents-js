## 실시간 에이전트 개요

![실시간 에이전트](https://cdn.openai.com/API/docs/images/diagram-speech-to-speech.png)

실시간 에이전트를 사용하면 OpenAI 음성-음성 모델을 기반으로 지연 시간이 짧은 음성 인터페이스를 구축할 수 있습니다. SDK는 Realtime API의 멘탈 모델을 그대로 유지하면서 원문 이벤트 흐름을 `RealtimeAgent`, `RealtimeSession` 및 전송 헬퍼로 래핑하여 도구, 가드레일, 핸드오프 및 세션 기록을 더 쉽게 다룰 수 있도록 합니다.

내부적으로는 공식 [WebRTC를 사용하는 Realtime API](https://developers.openai.com/api/docs/guides/realtime-webrtc/), [Realtime 대화](https://developers.openai.com/api/docs/guides/realtime-conversations/) 및 [음성 활동 감지](https://developers.openai.com/api/docs/guides/realtime-vad/) 가이드에서 설명하는 동일한 Realtime 개념이 그대로 적용됩니다. 실시간 에이전트 SDK는 이 API 위에 TypeScript 우선 계층을 추가하므로 전송 및 이벤트 처리를 처음부터 다시 구축하는 대신 제품 로직에 집중할 수 있습니다.

<Aside type="note">
  WebRTC로 브라우저 클라이언트를 연결하는 경우 빠른 시작부터 시작하세요. WebRTC,
  WebSocket, SIP, Twilio 또는 Cloudflare Workers 중에서 선택하려는 경우 먼저
  전송 방식 가이드를 살펴보세요.
</Aside>

## SDK 추가 기능

- 임시 클라이언트 토큰을 사용하는 브라우저 우선 WebRTC 설정
- 서버 측 WebSocket 및 SIP 전송 옵션
- 자동 인터럽션(중단 처리) 처리 및 로컬 대화 기록 업데이트
- 실시간 핸드오프를 통한 다중 에이전트 오케스트레이션
- 함수 도구, 호스티드 MCP 도구, 승인 및 위임 패턴
- 실시간 음성 상호작용을 위한 출력 가드레일 및 트레이싱 지원

## 음성-음성 방식의 이점

음성-음성 모델은 사용자 오디오를 직접 처리하므로 매 턴마다 별도의 음성-텍스트 변환, 텍스트 추론 및 텍스트-음성 변환 체인을 구축할 필요가 없습니다. 이를 통해 지연 시간을 줄이고 실시간 애플리케이션에서 인터럽션(중단 처리), 텍스트와 음성의 혼합 입력 및 도구 호출이 훨씬 자연스럽게 느껴지도록 할 수 있습니다.
