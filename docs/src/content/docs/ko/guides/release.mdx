## 버전 관리

이 프로젝트는 시맨틱 버전 관리 방식을 약간 수정한 `0.Y.Z` 형식을 따릅니다. 맨 앞의 `0`은 SDK가 아직 빠르게 발전하고 있음을 나타냅니다. 각 구성 요소는 다음과 같이 증가시킵니다.

## 마이너 (`Y`) 버전

베타로 표시되지 않은 공개 인터페이스에 **호환성이 깨지는 변경 사항**이 있으면 마이너 버전 `Y`를 증가시킵니다. 예를 들어, `0.0.x`에서 `0.1.x`로 업데이트할 때 호환성이 깨지는 변경 사항이 포함될 수 있습니다.

호환성이 깨지는 변경 사항을 원하지 않는다면 프로젝트에서 버전을 `0.0.x`로 고정하는 것이 좋습니다.

## 패치 (`Z`) 버전

호환성을 유지하는 변경 사항에는 `Z`를 증가시킵니다.

- 버그 수정
- 새로운 기능
- 비공개 인터페이스 변경
- 베타 기능 업데이트

## 하위 패키지 버전 관리

기본 `@openai/agents` 패키지는 독립적으로 사용할 수 있는 여러 하위 패키지로 구성되어 있습니다. 현재는 패키지 버전이 서로 연동되어 있어, 한 패키지의 버전이 올라가면 다른 패키지의 버전도 함께 올라갑니다. `1.0.0`으로 전환할 때 이 전략을 변경할 수 있습니다.

## 변경 로그

변경 사항을 파악하는 데 도움이 되도록 각 하위 패키지의 변경 로그를 생성합니다. 변경 사항이 하위 패키지에서 발생했을 수 있으므로, 자세한 내용을 확인하려면 해당 하위 패키지의 변경 로그를 살펴봐야 할 수 있습니다.
