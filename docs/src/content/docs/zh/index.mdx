## 概述

[适用于 TypeScript 的 OpenAI Agents SDK](https://github.com/openai/openai-agents-js) 是一个开源框架，用于在应用代码中构建智能体工作流。它基于 [Swarm](https://github.com/openai/swarm/tree/main) 构建，通过护栏和内置追踪，将轻量级多智能体编排引入生产应用。该 SDK 也[提供 Python 版本](https://github.com/openai/openai-agents-python)。

SDK 在您的应用中运行智能体循环，协调模型调用和工具执行，其中包括 MCP 服务器工具。会话可以在多次运行之间保留对话上下文，而人工审批机制则允许应用暂停工具执行以供审核。SDK 提供了一小组基础组件：

- **智能体**：配有 instructions 和工具的 LLM
- **沙盒智能体**：将智能体与隔离的文件系统工作区、Shell 命令、文件编辑、快照和沙盒会话状态结合使用
- **语音智能体**：支持低延迟语音交互，并提供工具、护栏、交接和对话历史记录
- **Agents as tools 和交接**：允许智能体将特定任务委派给其他智能体
- **护栏**：用于验证智能体的输入

这些基础组件与 TypeScript 结合后，功能足以表达工具与智能体之间的复杂关系，在智能体需要时为其提供真正的工作区，并让您无需经历陡峭的学习曲线即可构建实际应用。此外，SDK 还提供内置的**追踪**功能，让您能够可视化和调试智能体工作流、对其进行评估，甚至针对您的应用微调模型。

## 使用 Agents SDK 的理由

SDK 遵循两项核心设计原则：

1. 提供足够实用的功能，同时将基础组件控制在较少的数量，以便快速上手。
2. 开箱即用，同时允许您精确自定义具体行为。

以下是 SDK 的主要功能：

- **智能体循环**：内置智能体循环可处理工具调用，将结果发回 LLM，并持续运行直至任务完成。
- **沙盒执行**：当任务需要工作区时，可在包含隔离文件系统工作区、Shell 命令、文件编辑、快照和沙盒会话状态的环境中运行智能体。
- **语音智能体**：构建低延迟语音交互，并使用自动中断检测、上下文管理、护栏等功能。
- **TypeScript 优先**：使用 TypeScript 原生语言功能编排和串联智能体，无需学习新的抽象概念。
- **Agents as tools 和交接**：一种在多个智能体之间协调和委派工作的强大机制。
- **护栏**：与智能体执行并行运行输入验证和安全检查，并在检查未通过时快速失败。
- **函数工具**：将任意 TypeScript 函数转换为工具，并自动生成模式和执行基于模式的验证。
- **MCP 服务器工具调用**：内置集成，可将 MCP 服务器中的工具与函数工具一并提供给智能体。
- **会话**：用于在智能体循环中维持工作上下文的持久化记忆层。
- **人工干预**：用于在多次智能体运行过程中引入人工参与的内置机制。
- **追踪**：用于可视化、调试和监控工作流的内置追踪功能，并支持 OpenAI 的评估、微调和蒸馏工具套件。

## 安装

```bash
npm install @openai/agents zod
```

SDK 需要 Zod v4；通过 npm 安装 `zod` 将获取最新的 v4 版本。

## 起点选择

大多数初次使用者只需从以下入口之一开始：

| 起始选项 | 适用场景 | 说明 |
| --- | --- | --- |
| `@openai/agents` | 构建大多数文本、沙盒或实时应用。 | 推荐的默认选项。它包括 OpenAI 提供商配置、位于 `@openai/agents/sandbox` 下的沙盒智能体 API，以及位于 `@openai/agents/realtime` 下的实时 API。 |
| `@openai/agents-realtime` | 仅需要独立的 Realtime 包。 | 适用于纯浏览器实时应用，或需要更明确包边界的场景。 |
| 较低层级的软件包（`@openai/agents-core`、`@openai/agents-openai`、`@openai/agents-extensions`） | 需要较低层级的组合、自定义提供商连接配置或特定集成。 | 大多数新用户在有明确需求之前，可以忽略这些软件包。 |
