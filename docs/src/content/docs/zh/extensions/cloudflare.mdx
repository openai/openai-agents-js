Cloudflare Workers 和其他 workerd 运行时无法使用全局 `WebSocket` 构造函数建立出站 WebSocket 连接。为简化从这些环境连接语音智能体的过程，扩展包提供了一种专用传输机制，在内部通过 `fetch()` 完成连接升级。

<Aside type="caution">
  此适配器仍处于 Beta 阶段。您可能会遇到边界情况问题或错误。 请通过 [GitHub
  问题](https://github.com/openai/openai-agents-js/issues)
  报告任何问题，我们会尽快 修复。如需在 Workers 中使用 Node.js 风格的
  API，可考虑启用 `nodejs_compat`。
</Aside>

## 设置

<Steps>

1. **安装扩展包。**

   ```bash
   npm install @openai/agents-extensions
   ```

2. **创建传输实例并将其附加到会话。**

   <Code lang="typescript" code={cloudflareBasicExample} />

3. **连接您的 `RealtimeSession`。**

   ```typescript
   await session.connect({ apiKey: 'your-openai-ephemeral-or-server-key' });
   ```

</Steps>

## 注意事项

- Cloudflare 传输机制在底层使用带有 `Upgrade: websocket` 的 `fetch()`，并跳过对套接字 `open` 事件的等待，以适配 workerd API。
- 使用此传输机制时，所有 `RealtimeSession` 功能（工具、护栏等）均可正常使用。
- 在开发过程中，使用 `DEBUG=openai-agents*` 查看详细日志。
