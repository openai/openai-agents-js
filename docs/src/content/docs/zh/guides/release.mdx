## 版本管理

本项目采用略有调整的语义化版本管理方式，版本号格式为 `0.Y.Z`。开头的 `0` 表示 SDK 仍处于快速演进阶段。版本号的各部分按以下规则递增：

## 次版本（`Y`）

当任何未标记为 beta 的公共接口发生**破坏性变更**时，我们会递增次版本号 `Y`。例如，从 `0.0.x` 升级到 `0.1.x` 可能包含破坏性变更。

如果您不希望引入破坏性变更，建议在项目中将版本固定在 `0.0.x` 范围内。

## 补丁版本（`Z`）

对于非破坏性变更，我们会递增 `Z`：

- 错误修复
- 新功能
- 私有接口变更
- beta 功能更新

## 子包版本管理

主包 `@openai/agents` 由多个可独立使用的子包组成。目前，各包的版本号保持同步，即一个包的版本号递增时，其他包的版本号也会随之递增。在向 `1.0.0` 迈进的过程中，我们可能会调整这一策略。
