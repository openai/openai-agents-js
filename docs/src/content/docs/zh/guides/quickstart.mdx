## 项目设置

<Steps>

1. 创建项目并初始化 npm。此步骤只需执行一次。

   ```bash
   mkdir my_project
   cd my_project
   npm init -y
   ```

2. 安装 Agents SDK 和 Zod。SDK 将 Zod v4 用于工具模式和 structured outputs。

   ```bash
   npm install @openai/agents zod
   ```

3. 设置 OpenAI API 密钥。如果您还没有密钥，请按照[这些说明](https://platform.openai.com/docs/quickstart#create-and-export-an-api-key)创建 OpenAI API 密钥。

   ```bash
   export OPENAI_API_KEY=sk-...
   ```

   您也可以调用 `setDefaultOpenAIKey('<api key>')` 以编程方式设置密钥，并使用 `setTracingExportApiKey('<api key>')` 设置用于追踪的密钥。有关更多详情，请参阅 [SDK 配置](/openai-agents-js/zh/guides/config)指南。

</Steps>

## 追踪记录的查看

Agents SDK 会自动生成追踪记录。您可以通过这些记录查看智能体的运行情况、调用了哪些工具，以及哪些智能体接收了交接。

要查看智能体运行期间发生的情况，请前往 [OpenAI 控制台中的追踪查看器](https://platform.openai.com/traces)。
