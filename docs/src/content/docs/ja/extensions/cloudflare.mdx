Cloudflare Workers やその他の workerd ランタイムでは、グローバルの `WebSocket` コンストラクターを使用して外向きの WebSocket 接続を確立できません。これらの環境から音声エージェントを簡単に接続できるように、extensions パッケージには、`fetch()` ベースのアップグレードを内部で実行する専用のトランスポートが用意されています。

<Aside type="caution">
  このアダプターはまだベータ版です。エッジケースでの問題やバグが発生する可能性があります。
  問題が発生した場合は [GitHub
  のイシュー](https://github.com/openai/openai-agents-js/issues)
  からご報告ください。迅速に修正します。 Workers で Node.js スタイルの API
  を使用する場合は、`nodejs_compat` の有効化を検討してください。
</Aside>

## セットアップ

<Steps>

1. **extensions パッケージをインストールします。**

   ```bash
   npm install @openai/agents-extensions
   ```

2. **トランスポートを作成し、セッションに設定します。**

   <Code lang="typescript" code={cloudflareBasicExample} />

3. **`RealtimeSession` を接続します。**

   ```typescript
   await session.connect({ apiKey: 'your-openai-ephemeral-or-server-key' });
   ```

</Steps>

## 注意事項

- Cloudflare トランスポートは、内部で `Upgrade: websocket` を指定した `fetch()` を使用し、workerd の API に合わせてソケットの `open` イベントを待機しません。
- このトランスポートを使用しても、`RealtimeSession` のすべての機能（ツール、ガードレールなど）は通常どおり動作します。
- 開発中に詳細なログを確認するには、`DEBUG=openai-agents*` を使用してください。
