## プロジェクトのセットアップ

<Steps>

1. プロジェクトを作成し、npm を初期化します。この操作は一度だけ行えば十分です。

   ```bash
   mkdir my_project
   cd my_project
   npm init -y
   ```

2. Agents SDK と Zod をインストールします。SDK はツールのスキーマと structured outputs に Zod v4 を使用します。

   ```bash
   npm install @openai/agents zod
   ```

3. OpenAI API キーを設定します。まだお持ちでない場合は、[こちらの手順](https://platform.openai.com/docs/quickstart#create-and-export-an-api-key)に従って OpenAI API キーを作成してください。

   ```bash
   export OPENAI_API_KEY=sk-...
   ```

   または、`setDefaultOpenAIKey('<api key>')` を呼び出してプログラムでキーを設定し、トレーシングには `setTracingExportApiKey('<api key>')` を使用することもできます。詳しくは、[SDK の設定](/openai-agents-js/ja/guides/config)をご覧ください。

</Steps>

## トレースの確認

Agents SDK はトレースを自動的に生成します。これらのトレースを使用すると、エージェントがどのように動作しているか、どのツールを呼び出したか、どのエージェントがハンドオフを受け取ったかを確認できます。

エージェントの実行中に何が起きたかを確認するには、[OpenAI ダッシュボードのトレースビューアー](https://platform.openai.com/traces)にアクセスしてください。
