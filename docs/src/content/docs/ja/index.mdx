## 概要

[TypeScript 向け OpenAI Agents SDK](https://github.com/openai/openai-agents-js) は、アプリケーションコード内でエージェントワークフローを構築するためのオープンソースフレームワークです。[Swarm](https://github.com/openai/swarm/tree/main) を基盤とし、軽量なマルチエージェントオーケストレーションを、ガードレールと組み込みのトレーシングとともに本番アプリケーションへ導入します。SDK は [Python 版も提供されています](https://github.com/openai/openai-agents-python)。

SDK はアプリケーション内でエージェントループを実行し、MCP サーバーツールを含むモデル呼び出しとツール実行を連携させます。セッションは実行間で会話コンテキストを保持し、人間による承認を使用すると、レビューのためにツール実行を一時停止できます。SDK は、次の少数の基本コンポーネントを提供します。

- **エージェント**：指示とツールを備えた LLM
- **サンドボックスエージェント**：エージェントと、分離されたファイルシステムワークスペース、シェルコマンド、ファイル編集、スナップショット、サンドボックスセッション状態を組み合わせたもの
- **音声エージェント**：ツール、ガードレール、ハンドオフ、会話履歴を備えた低遅延の音声対話をサポートするもの
- **Agents as tools とハンドオフ**：特定のタスクをほかのエージェントに委任できるようにするもの
- **ガードレール**：エージェントへの入力を検証できるようにするもの

これらの基本コンポーネントを TypeScript と組み合わせることで、ツールとエージェント間の複雑な関係を表現し、必要に応じてエージェントに実際のワークスペースを提供し、高い学習コストをかけずに実用的なアプリケーションを構築できます。さらに SDK には、エージェントフローの可視化とデバッグに加え、評価や、アプリケーション向けモデルのファインチューニングも可能にする組み込みの **トレーシング** が含まれています。

## Agents SDK を使用する理由

SDK の設計には、次の 2 つの基本原則があります。

1. 利用する価値がある十分な機能を備えながら、すぐに習得できるほど基本コンポーネントを少数に抑えること。
2. そのままでも優れた動作をしつつ、実際の処理を細部までカスタマイズできること。

SDK の主な機能は次のとおりです。

- **エージェントループ**：ツールの呼び出しを処理し、結果を LLM に返し、タスクが完了するまで継続する組み込みのエージェントループ
- **サンドボックス実行**：作業にワークスペースが必要な場合に、分離されたファイルシステムワークスペース、シェルコマンド、ファイル編集、スナップショット、サンドボックスセッション状態を使用してエージェントを実行
- **音声エージェント**：自動割り込み検出、コンテキスト管理、ガードレールなどの機能を備えた低遅延の音声対話を構築
- **TypeScript ファースト**：新しい抽象概念を習得することなく、TypeScript のネイティブな言語機能を使用してエージェントをオーケストレーションし、連鎖
- **Agents as tools とハンドオフ**：複数のエージェント間で作業を調整し、委任するための強力な仕組み
- **ガードレール**：入力検証と安全性チェックをエージェントの実行と並行して行い、チェックに合格しなかった場合は即座に失敗
- **関数ツール**：任意の TypeScript 関数を、スキーマの自動生成とスキーマベースの検証を備えたツールに変換
- **MCP サーバーツール呼び出し**：MCP サーバーのツールを関数ツールとともにエージェントへ公開する組み込み連携
- **セッション**：エージェントループ内の作業コンテキストを維持するための永続的なメモリレイヤー
- **Human in the loop (人間の介入)**：複数のエージェント実行にわたって人間を関与させるための組み込みの仕組み
- **トレーシング**：ワークフローを可視化、デバッグ、監視するための組み込みトレーシング。OpenAI の評価、ファインチューニング、蒸留ツールスイートをサポート

## インストール

```bash
npm install @openai/agents zod
```

SDK には Zod v4 が必要です。npm で `zod` をインストールすると、最新の v4 リリースが取得されます。

## 開始点の選択

初めて利用する場合、ほとんどは次のいずれかのエントリーポイントだけで十分です。

| 開始点 | 使用する場面 | 備考 |
| --- | --- | --- |
| `@openai/agents` | ほとんどのテキスト、サンドボックス、リアルタイムアプリケーションを構築する場合 | 推奨されるデフォルトです。OpenAI プロバイダーの設定、`@openai/agents/sandbox` 配下のサンドボックスエージェント API、`@openai/agents/realtime` 配下のリアルタイム API が含まれます。 |
| `@openai/agents-realtime` | スタンドアロンの Realtime パッケージだけが必要な場合 | ブラウザー専用のリアルタイムアプリ、またはパッケージ境界をより限定したい場合に役立ちます。 |
| 低レベルパッケージ（`@openai/agents-core`、`@openai/agents-openai`、`@openai/agents-extensions`） | 低レベルの構成、カスタムプロバイダーの接続、または特定の連携が必要な場合 | ほとんどの新規ユーザーは、具体的な必要性が生じるまで無視できます。 |
