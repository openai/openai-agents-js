Twilio offers a [Media Streams API](https://www.twilio.com/docs/voice/media-streams) that sends the raw audio from a phone call to a WebSocket server. Use this API to connect your [voice agents](/openai-agents-js/guides/voice-agents) to Twilio. The default Realtime Session transport in `websocket` mode can connect Twilio events to your Realtime Session. You must set the audio format and adjust interruption timing because phone calls introduce more latency than web-based conversations.

The dedicated Twilio transport handles the connection, interruptions, and audio forwarding.

## Setup

<Steps>

1. **Make sure you have a Twilio account and a Twilio phone number.**

2. **Set up a server that authenticates requests from Twilio.**

   For local development, configure a tunnel such as [`ngrok`](https://ngrok.io/) or [Cloudflare Tunnel](https://developers.cloudflare.com/pages/how-to/preview-with-cloudflare-tunnel/) to make your local server accessible to Twilio. The server must validate `X-Twilio-Signature` on both the incoming call webhook and the WebSocket upgrade before creating a transport or connecting to OpenAI. Use the [official Twilio request validator](https://www.twilio.com/docs/usage/security), the account's primary Auth Token, and a configured public URL. Do not derive that URL from request Host or forwarded headers. `TwilioRealtimeTransportLayer` receives an already authenticated WebSocket; the adapter does not authenticate HTTP requests.

3. [Build the classic extensions](https://github.com/openai/openai-agents-js/blob/feat/codex-harness/packages/agents/examples/guides/installation.md#run-the-classic-extensions).

## Tips and considerations

1. **Speed is the name of the game.**

   To receive all necessary events and audio from Twilio, create your `TwilioRealtimeTransportLayer` instance as soon as the authenticated WebSocket connection is available. Call `session.connect()` immediately afterward.

2. **Access the raw Twilio events.**

   To access raw Twilio events, listen for `transport_event` on your `RealtimeSession` instance. Every Twilio event has the type `twilio_message` and a `message` property that contains the raw event data.

3. **Watch debug logs.**

   Set `DEBUG=openai-agents*` to show all Agents SDK debug logs. To show only Twilio adapter debug logs, set `DEBUG=openai-agents:extensions:twilio*`.

## Full example server

The [runnable Twilio example](https://github.com/openai/openai-agents-js/tree/main/examples/realtime-twilio) includes authenticated Fastify routes and Realtime session setup. Its README describes the required server-side `OPENAI_API_KEY`, `TWILIO_AUTH_TOKEN`, and `TWILIO_PUBLIC_BASE_URL` settings. The public base URL is an HTTPS origin without a path prefix, query string, or fragment. Update that setting when a tunnel's public origin changes.

The server rejects invalid call and upgrade signatures before opening a Realtime connection. Twilio Media Stream URLs use `wss://` and do not support query parameters. See the [Twilio Stream documentation](https://www.twilio.com/docs/voice/twiml/stream) for custom parameters.
