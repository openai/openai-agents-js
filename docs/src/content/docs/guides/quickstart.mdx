This guide uses `@openai/agents/classic`. For new text agents, start with the [native v1 preview](https://github.com/openai/openai-agents-js/blob/feat/codex-harness/examples/codex/README.md). When upgrading a v0 workflow, we recommend [moving directly to native v1](https://github.com/openai/openai-agents-js/blob/feat/codex-harness/examples/codex/guides/migration.md). Use classic only if you need to stage that migration.

<Aside type="note" title="Looking for sandbox agents?">
  This quickstart builds a text agent that runs in your app process. If you want
  an agent with an isolated filesystem workspace, shell commands, and sandbox
  session state, start with the [Sandbox agents
  quickstart](/openai-agents-js/guides/sandbox-agents).
</Aside>

## Project Setup

<Steps>

1. Create a project and initialize npm once.

   ```bash
   mkdir my_project
   cd my_project
   npm init -y
   ```

2. [Install the alpha SDK](https://github.com/openai/openai-agents-js/blob/feat/codex-harness/examples/codex/guides/installation.md#add-the-sdk-to-an-existing-application) to use the `@openai/agents/classic` import shown below. The manifest includes Zod 4 for tool schemas and structured outputs. Install `tsx` to run the TypeScript examples.

   ```bash
   npm install --save-dev tsx
   ```

3. Set an OpenAI API key. If you don't have one, follow [these instructions](https://platform.openai.com/docs/quickstart#create-and-export-an-api-key) to create an OpenAI API key.

   ```bash
   export OPENAI_API_KEY=sk-...
   ```

   Alternatively you can call `setDefaultOpenAIKey('<api key>')` to set the key programmatically and use `setTracingExportApiKey('<api key>')` for tracing. See [the config guide](/openai-agents-js/guides/config) for more details.

</Steps>

## View your traces

The Agents SDK generates traces that show how your agents ran, which tools they called, and which agents received handoffs.

To review your agent run, open the [Trace viewer in the OpenAI Dashboard](https://platform.openai.com/traces).
