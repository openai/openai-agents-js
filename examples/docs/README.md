# Documentation Snippets

This directory contains small scripts used throughout the documentation. Type-check all snippets with:

```bash
pnpm -F docs-code build-check
```

Snippets are grouped by documentation section under directories such as `agents/`, `guardrails/`, `models/`, `running-agents/`, `sandbox-agents/`, `sessions/`, `streaming/`, `tools/`, and `voice-agents/`. Add each snippet next to the section that imports it so the directory structure remains the source of truth.
