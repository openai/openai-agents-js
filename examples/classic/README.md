# Classic examples

These examples use the retained classic SDK. See the [classic API guide](../../packages/agents/CLASSIC.md) for its entry points.

Use Node.js 24 and the [pnpm version pinned in `package.json`](../../package.json). Each example directory has its own `package.json` with setup and start commands. From the repository root, install dependencies and build the SDK:

```sh
pnpm install --frozen-lockfile
pnpm build
```

Most text examples require `OPENAI_API_KEY` in the server environment. Browser Realtime examples use a short-lived client secret generated by their server-side token command.

For example, run `pnpm examples:basic` for a basic agent or `pnpm examples:realtime-demo` for the Realtime demo. Check the selected example's README for credentials and other prerequisites.

For the native Codex runtime, use the [Codex examples](../codex/README.md).
