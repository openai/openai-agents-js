# Memory examples

## Runtime requirements

Use Node.js 22.18 or later within the 22.x line, Node.js 24.x, or Node.js 26 or later. The following commands execute TypeScript directly with Node.js: `start:memory`, `start:memory-hitl`, `start:hitl-session-scenario`, `start:oai`, `start:oai-hitl`, `start:oai-compact`, `start:oai-compact-stateless`, `start:file`, `start:file-hitl`.
